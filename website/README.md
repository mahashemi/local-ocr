# Persian Dars Learning Website

Place the main website HTML at `website/index.html`.

Supporting files belong in:

- `assets/css/` for stylesheets
- `assets/js/` for JavaScript
- `assets/images/` for images and diagrams

The website will be published from this directory using GitHub Pages via GitHub Actions. Keep private PDFs, OCR checkpoints, and unreviewed source material out of this directory.
