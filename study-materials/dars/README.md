# OCR Study Materials

Place one cleaned OCR text file per lesson/document in this directory, for example:

- `dars-01.txt`
- `dars-02.txt`

Keep original PDFs and page-level OCR checkpoints in local-only `data/`; do not upload them here.

**Visibility notice:** this repository is public. Files committed here are publicly accessible. Only upload OCR text that you have the right to share publicly.
