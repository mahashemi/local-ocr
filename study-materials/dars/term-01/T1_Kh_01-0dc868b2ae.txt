مثال۱: ایران + ی < ایرانی مثال ۲: لبنان + ی < لبنانی مثال۲: پاکستان + ی < پاکستانی
نکتة اول: اگر حرف آخر نام کشوری «» یا « خو» بو به جای اضافه کردن «ی» از پسوند «بی» استفاده می‌کنیم
منال۱: آفریقا + یی - آفریقایی منال۲: آسیا + یی - آسیایی
منال۲: آمریکا + یی < آمریکایی مثال۴: پرو + بی < پروبی
نکتة دوم: اگر حرف آخر نام کشوری «۵» بود» به جای اضافه کردن «ی» از پسوند «ای» استفاده می‌کنیم.
مثال۱: روسیه + ای < روسیه‌ای مثال۲: سوریه + ای < سوریه‌ای
مثال۲: ترکیه + ای < ترکیه‌ای
نکن سوم: اگر حرف آخر نام کشوری «ی» بود به جای اضافه کردن «ی» از پسوند اب استفاده می‌کنیم
منال۲: البانی + ایی < البانیایی
منال۱: مالزی - مالزیایی/ مالایی
